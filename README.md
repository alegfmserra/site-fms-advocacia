# Ferreira & Moreira Serra Advogados Associados — site

Site institucional do escritório (São Luís/MA, atuação nacional via processo eletrônico).

- **Tecnologia:** HTML, CSS e JavaScript puros — sem build. Publicado pelo GitHub Pages.
- **No ar:** https://alegfmserra.github.io/site-fms-advocacia/
- **Ver localmente:** `node scripts/servir.js` e abrir http://localhost:4321
- **Atualizar vídeos do canal:** `node scripts/atualizar-videos.js`
- **Instruções de manutenção (para pessoas e para o Claude):** [CLAUDE.md](CLAUDE.md)

Conteúdo de caráter informativo, nos termos do Provimento 205/2021 do CFOAB.
